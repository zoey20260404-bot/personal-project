就# 产品方案：公考参谋部 v1.0（智能选岗参谋）

## 一、项目定位

- **一句话**：基于多 Agent 协作的智能公考选岗分析系统，通过 OCR 识别用户条件，结合历年职位数据和竞争情报，输出"冲-稳-保"三档选岗策略。
- **核心价值**：不是"你能报哪些岗"，而是"你应该报哪个岗"——从信息检索升级为竞争策略分析。

## 二、MVP 核心场景

**主路径：**

1. 用户上传职位表截图 或 输入自身条件
2. 系统识别/解析用户条件（学历、专业、政治面貌、应届身份等）
3. Agent 检索匹配岗位，调取历年分数线、报录比
4. Agent 生成选岗分析报告（冲/稳/保三档）
5. 用户多轮追问（对比岗位、询问待遇、确认专业匹配度）
6. 用户收藏心仪岗位

**两种用户模式：**

- **0 基础模式**：逐项引导提问，输出详细解释（含考公基础概念科普）
- **进阶模式**：自然语言快速输入，输出精简数据和策略结论

## 三、用户旅程地图

### 路径 A：0 基础用户（详细引导）

```plain
打开系统
↓
Agent 问候："你好，我是你的选岗参谋。你是第一次参加公务员考试吗？"
↓ 用户选择"是的"
进入引导模式，Agent 依次询问：
- 学历（大专/本科/硕士/博士）
- 专业（可上传毕业证 OCR 识别或手动输入）
- 是否应届生（是/否，毕业几年）
- 政治面貌（群众/团员/党员/预备党员）
- 目标省份（可多选）
- 基层工作经验（无/1年/2年/3年+）
- 是否接受户籍限制
↓
Agent 确认："我识别到你的条件是：本科-计算机科学与技术-应届-党员-广东。对吗？"
↓ 用户确认或修改
Agent 展示 Loading："正在分析 2024-2026 年职位表数据..."
↓
Agent 输出详细选岗报告（含解释性文字）
↓
用户追问（多轮对话）：
- "A岗和B岗哪个更好？"
- "我的党员身份有什么优势？"
- "软件工程能报计算机类吗？"
- "这个岗有没有暗坑？"
↓
用户收藏岗位，Agent 提示报名期间将持续监控竞争数据
```

### 路径 B：进阶用户（精简快速）

```plain
用户直接输入：
"帮我筛广东省考，计算机本科，党员，应届，广州深圳"
或上传职位表截图直接圈选
↓
Agent 秒级解析，输出精简版匹配结果
↓
展示排序列表（按上岸概率/待遇/发展排序）
↓
用户可追问深度问题：
- "这3个岗历年分数线趋势？"
- "如果求稳排除法怎么选？"
- "该单位工作强度和待遇？"
```

## 四、核心功能模块

### 4.1 输入层

- **OCR 识别**：支持上传官方职位表截图（印刷体），提取岗位信息
- **自然语言输入**：用户直接描述自身条件
- **表单输入**：结构化填写（OCR 失败时的降级方案）
- **专业 OCR**：支持上传毕业证/学位证，识别专业名称

### 4.2 条件解析与匹配

- **硬条件过滤**：学历、专业、政治面貌、应届、基层年限、户籍
- **专业大类智能匹配**：建立"专业→专业类→学科门类"映射（如"软件工程"属于"计算机类"）
- **智能纠错**：用户说"我是计算机专业"，Agent 自动确认是"计算机科学与技术"还是"计算机类"

### 4.3 竞争分析 Agent

- **历史数据调取**：2024-2026 年进面分数线、报录比
- **竞争烈度评估**：结合限制条件数量、地域热度、单位层级
- **风险提示**：识别"三不限倾向岗""备注暗坑（如服务期、加班、体测）"

### 4.4 策略生成 Agent

**输出标准格式：**

- **冲刺档（1 个）**：条件匹配但分数较高，适合模考成绩好的用户
- **稳妥档（2 个）**：匹配度高、历年数据稳定、限制条件较多
- **保底档（1 个）**：限制条件极多、竞争比低、确保有岗可上

**每个岗位附：**

- 匹配理由（人话解释，非数据罗列）
- 历年分数线参考
- 竞争比预估
- 备注提醒（如"需 24 小时值班""服务期 5 年"）

### 4.5 多轮对话 Agent

**支持追问类型：**

- 岗位对比（A vs B）
- 专业匹配度确认（"我这个专业能不能报"）
- 待遇与发展咨询
- 报名策略咨询（"什么时候报名最好"）
- 风险提示解读（"服务期 5 年意味着什么"）

### 4.6 用户资产

- **岗位收藏**：用户可收藏心仪岗位，系统持久化存储
- **报告历史**：保存每次选岗分析报告，支持回看
- **模式切换**：0 基础/进阶模式可随时切换

## 五、数据层（RAG 知识库）

| 数据类型 | 内容 | MVP 要求 |
| --- | --- | --- |
| 职位表 | 2024-2026 年国考+省考官方职位表 | 先支持 1-2 个省份+国考，求质不求量 |
| 进面分数线 | 历年各岗位进面最低分/最高分 | 至少 2 年历史数据 |
| 报录比 | 报名截止日竞争数据 | 用于竞争烈度分析 |
| 专业目录 | 教育部专业目录+各省公务员专业目录 | 核心，解决专业大类匹配问题 |
| 岗位备注解读 | 常见备注标签的人工标注 | "服务期""加班""体测"等实际影响 |
| 待遇情报 | 公开信息整理 | 非精确，用于相对排序和参考 |

## 六、版本规划

**v1.0（当前 MVP）：智能选岗参谋**

- 核心：条件输入 → 智能匹配 → 竞争分析 → 冲稳保推荐 → 多轮追问 → 收藏
- 输入：OCR + 自然语言 + 表单
- 输出：图文报告
