# feat003 需求文档：多 Agent 记忆体系（权责划分与经验沉淀）

> 版本：v1.0 日期：2026-09-07
> 关联：feat002（多轮对话中枢） · feat001（条件解析/档案）

## 1. 背景

feat002 初版记忆实现存在维度错乱：所有会话消息双写进长期向量库（噪音 + 成本）、召回在路由前写死 Agent 名、三层作用域全部按 agent 过滤导致跨 Agent 失忆。本需求重新定义记忆的权责与作用域语义。

## 2. 记忆权责模型

| 内容 | 存哪 | 作用域 | 归属 | 生命周期 |
| --- | --- | --- | --- | --- |
| 原始对话消息 | Redis 会话缓冲 | session | 编排层（ChatService） | 20 条 / 2h TTL |
| 用户画像事实（档案变更、收藏偏好） | pgvector | user | 业务规则触发写入 | 长期，跨 Agent 共享 |
| Agent 经验洞察 | pgvector | agent | 各 Agent 自召回、自沉淀 | 长期，按 Agent 隔离 |

原则：**编排层管"对话流水"，Agent 管"自己的心得"，画像大家共享**。

## 3. 功能需求

1. **召回时机**：Agent 经验在执行开始时由目标 Agent 自己召回（不在路由前统一召回）
2. **作用域语义**：召回时 agent 作用域按 Agent 名隔离；session/user 不按 Agent 过滤
3. **经验沉淀双通道**：
   - 规则触发：档案变更、收藏行为等明确信号 → 自动写入 user 作用域
   - 自主沉淀：Agent 经 `save_insight` 工具（白名单控制）主动沉淀 agent 作用域经验
4. **噪音控制**：原始闲聊消息不进长期向量库
5. **安全**：`save_insight` 的 Agent 名从执行上下文取（节点注入），模型无法冒充其他 Agent 写记忆

## 4. 验收标准

- 用户说"我入党了"→ 档案更新 + user 作用域写入画像记忆
- Agent 发现规律调 save_insight → 写入自己的 agent 作用域，其他 Agent 召回不到
- 跨 Agent 切换话题 → 短期对话历史连续（不"失忆"），但经验互不污染
- pgvector 中无原始闲聊消息
