# feat004 需求文档：选岗推荐（冲稳保主链路）

> 版本：v1.0 日期：2026-09-07

## 1. 背景与目标

产品核心价值闭环：用户条件 → 智能匹配 → 竞争分析 → 冲稳保推荐 → 图文报告。

前置数据已就绪：岗位库（2026 国考 20714 条）、进面分数线（7300 岗）、专业大类归一、用户档案。

## 2. 触发方式

**仅 chat 入口**（本阶段不在解析页加按钮）：用户对选岗参谋说"帮我生成选岗报告/推荐岗位" → advisor 调 `run_advise` 工具触发。

## 3. 功能需求

### 3.1 四阶段流水线

| 阶段 | 职责 | 类型 |
| --- | --- | --- |
| Researcher | 按档案六维硬条件检索候选岗位（纯规则 SQL） | 代码节点 |
| Analyzer | 竞争烈度分析（进面分 + 限制条件数）+ 备注暗坑解读 | 规则 + LLM |
| Strategist | 冲稳保三档分组 + 推荐理由（LLM，低温） | LLM 节点 |
| Responder | 生成图文报告（按用户模式选表达变体） | LLM 节点 |

### 3.2 竞争代理指标（报录比缺口替代）

真实报录比需报名季统计数据（暂无）。MVP 用代理指标：进面分数（趋势）+ 限制条件数量 + 进面比例。

### 3.3 输出要求（PRD 2.5）

- 冲刺档 1 个 / 稳妥档 2 个 / 保底档 1 个
- 每岗附：推荐理由（人话）、历年分数线、竞争比预估、备注提醒
- beginner 模式详细解释（≥500 字），advanced 模式精简结论（≤200 字）

### 3.4 报告持久化与回显

- 报告生成过程 SSE 流式展示（进度 + 内容）
- 落库 reports 表，支持列表/详情回看
- 报告中的岗位可一键收藏

## 4. 非功能需求

- 全链路超时控制（单节点 90s）
- 任一节点失败的降级策略：Researcher 无候选 → 提示放宽条件；LLM 节点失败 → 规则化简版报告
- TraceID 贯穿 chat → flow 全链路
- 报告引用数据必须来自真实岗位库（禁止编造）

## 5. 验收标准

- chat 输入"帮我生成选岗报告" → SSE 可见进度 → 输出含冲稳保三档的报告 → 报告落库可回看
- 报告中的岗位 ID 都能在 positions 表查到
- 无档案用户触发 → 引导先完成条件解析
