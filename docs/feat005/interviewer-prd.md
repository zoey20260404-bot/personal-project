# feat005 需求文档：结构化面试考官与聊天输入体验

## 1. 目标与范围

在现有多轮追问中增加结构化面试练习能力，沿用 Router、ReAct、SSE 和配置装配。用户直接输入“练习面试”或“模拟一场结构化面试”，后续作答、追问、点评在同一对话中完成。不新增页面、Tab、独立面试入口或会话流程，不调整现有框架。

## 2. 功能需求

- 练习模式：默认模式，一次一道题，作答后即时点评和改进示例；按用户要求追问或进入下一题。
- 模拟模式：用户要求模拟面试时启用，默认三道主问题，可指定题数；每题最多追问一次，完成或提前结束时统一点评。
- 支持自然语言跳题、切换模式、结束和重新开始。跳过的题不虚构作答，结束后不自动开新一轮。
- 覆盖综合分析、组织计划、人际沟通、应急应变、岗位认知等模拟题，优先遵循用户指定背景，不冒充官方真题。
- 点评依据实际作答，覆盖审题、逻辑结构、措施可行性、文字表达，并给出改进建议。用户要求分数时仅给练习参考，不冒充官方评分，不判断声音或仪态。
- 面试情境回答不视为真实档案修改；明确转向选岗等任务时允许切换 Agent。
- 使用现有短期历史承接进度；超出 20 条窗口时仅评价可见答案，请用户补充缺失内容。beginner/advanced 仍只控制表达风格。

## 3. Web 交互

仅完善现有“多轮追问”：增加自然语言面试提示，支持分段作答，Enter 换行、Ctrl/⌘+Enter 发送，输入法组词时不误发送。回复保留换行，回复期间防重复发送，请求失败且无新草稿时恢复原作答。

输入区居中限宽，输入框、快捷键提示和右下角发送按钮组成一个整体。输入随内容自动增高，发送后恢复紧凑高度；窄屏下适应可用宽度。

## 4. 验收场景

1. 练习面试 → 一道模拟题 → 作答 → 即时点评 → 请求追问或下一题。
2. 模拟面试 → 三题逐题作答（必要时追问）→ 结束后统一点评，过程中不泄露参考答案。
3. 不含“面试”关键词的回答仍承接当前题目；明确要求查岗位时切换到选岗 Agent。
4. 跳题、未作答即结束、切换模式、重新开始，以及缺失历史时不虚构答案。
5. 多行输入、快捷键、回复换行、防重复发送、失败草稿恢复及宽窄屏输入区样式。
