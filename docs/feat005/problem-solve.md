# feat005 问题与处理

> 分支：`feature/chenziyu/feat005`。关联：[需求文档](interviewer-prd.md) · [技术文档](tech-design.md)。

## 面试作答被路由为其他意图

原 Router 只收到当前消息，无法把“我先安抚群众”与前轮面试题关联。现在复用原有 composeInput，将历史同时传给 Router 和考官，提示词区分情境作答和真实档案修改；明确的新任务仍允许切换。历史读取扩为现有缓冲的 20 条，长会话超出窗口时要求补充缺失答案。

## 无工具配置缺少执行层校验

原 ReAct 只限制发给模型的工具列表，收到调用后直接查全局注册表。新增执行前白名单校验，模型伪造调用会失败，不执行任何越权工具；回归测试验证执行次数为零。

## 输入框过宽、发送按钮被拉伸

用户反馈原 textarea 横向铺满，发送按钮与输入框等高，显得过重。现将原输入区改为居中、最大宽度 1080px 的一体式容器，右下角放固定高度发送按钮，快捷键提示单独展示。输入按内容增高至 180px，发送后恢复紧凑高度；仍使用原多轮追问入口。
